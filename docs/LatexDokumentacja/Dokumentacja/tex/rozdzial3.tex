\subsection{Narzędzia programistyczne i kontrola wersji}

\hspace{0.60cm}Prace nad projektem realizowano z wykorzystaniem następującego oprogramowania:
\begin{itemize}
    \item \textbf{Android Studio:} Oficjalne zintegrowane środowisko programistyczne (IDE) dla systemu Android, zapewniające zaawansowane wsparcie dla języka Kotlin, wbudowany emulator oraz narzędzia do projektowania layoutów UI w technologii Jetpack Compose.
    \item \textbf{Git oraz GitHub:} System kontroli wersji służący do śledzenia zmian w kodzie źródłowym, tworzenia gałęzi (\textit{branches}) oraz wspólnej pracy zespołowej nad projektem.
\end{itemize}

\subsection{Wybór bibliotek i struktura klas}

\hspace{0.60cm}W aplikacji wykorzystano nowoczesne biblioteki systemowe Android oraz komponenty języka Kotlin:
\begin{itemize}
    \item \textbf{\texttt{MediaPlayer}:} Wbudowana klasa systemowa odpowiedzialna za ładowanie, buforowanie i odtwarzanie krótkich próbek audio w formacie MP3/OGG.
    \item \textbf{\texttt{Kotlin Coroutines}:} Mechanizm obsługi operacji asynchronicznych, wykorzystywany do zarządzania czasem rundy (timerem) oraz komunikacji sieciowej bez blokowania głównego wątku interfejsu (\textit{UI Thread}).
\end{itemize}

\subsection{Projekt integracji z zewnętrznym API (Deezer)}

\hspace{0.60cm}W celu zapewnienia dynamicznej bazy utworów muzycznych, aplikacja została zaprojektowana jako klient publicznego interfejsu \textbf{Deezer API}. Architektura komunikacji sieciowej opiera się na protokole HTTP oraz deserializacji odpowiedzi w formacie JSON. 

Główne endpointy wykorzystane w projekcie obejmują:
\begin{itemize}
    \item \textbf{Wyszukiwanie playlist (\texttt{/search/playlist?q=}):} Umożliwia użytkownikowi odnalezienie list odtwarzania na podstawie zapytania tekstowego.
    \item \textbf{Pobieranie zawartości playlisty (\texttt{/playlist/\{id\}}):} Służy do pobierania listy unikalnych identyfikatorów utworów przypisanych do wybranej playlisty.
    \item \textbf{Pobieranie szczegółów i próbek utworu (\texttt{/track/\{id\}}):} Zwraca metadane utworu (tytuł, wykonawca, okładka albumu) oraz bezpośredni adres URL do 30-sekundowej próbki dźwiękowej (\textit{preview}), która jest odtwarzana w rundzie.
\end{itemize}
